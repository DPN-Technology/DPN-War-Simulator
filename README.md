# DPN War Simulator

DPN Technology's large-scale 3D war simulation project focused on immersive first-person gameplay, realistic vehicles and ships, seamless environments, combat systems and an expanding open-world simulation.

## Development Priorities
- Realistic environments and production-quality assets
- Seamless traversal through ships, rooms, decks and world spaces
- Advanced vehicle and ship physics
- AI, combat, damage and world simulation
- Performance profiling and optimization
- Reproducible builds, CI and supply-chain evidence

See the repository documentation, roadmap and build instructions for implementation details.
