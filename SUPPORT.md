# Support

This repository is a private DPN Technology project.

## Bug Reports

Use the repository's **Bug report** issue form for reproducible defects. Include:
- Application version
- Affected component
- Reproduction steps
- Expected behavior
- Sanitized logs/screenshots where useful

Do not attach credentials, private databases, employee/customer information, tokens, keys, or other sensitive data.

## Feature Requests

Use the **Feature request** issue form for new capabilities, workflow improvements, integrations, or usability proposals.

Good requests should describe:
- The operational/user problem
- The proposed outcome
- Affected systems
- Security or data implications
- Acceptance criteria

## Security Issues

Do **not** report sensitive vulnerabilities through a normal issue.

Follow `SECURITY.md` and use GitHub private vulnerability reporting if available, or an established private DPN Technology security/administrative channel.

## Pull Requests

Follow `CONTRIBUTING.md` and the repository pull-request checklist. CI must pass before a change should be considered release-ready.

## Release Questions

See `RELEASE_PROCESS.md` for versioning, release validation, tagging, artifact, and rollback expectations.
