# DPN War Simulator Release Notes

## Current release line

DPN War Simulator is the DPN Technology military simulation project focused on immersive first-person environments, realistic vehicle/ship systems, large continuous spaces, interactive crew operations, and progressively higher-fidelity gameplay systems.

## Release priorities

- Stable first-person movement and input handling
- Large continuous environments with minimal interruption
- Realistic ship and vehicle movement/physics
- Higher-fidelity art, lighting, materials, and environments
- Interactive rooms, decks, systems, and crew workflows
- Performance optimization and regression testing
- Reproducible builds and clear installation guidance

## Release discipline

Every release should be traceable to a verified source commit and include release notes, checksums, and supply-chain evidence where supported. Large generated assets, secrets, private build credentials, and machine-specific caches should not be committed unless intentionally versioned.

See `README.md`, `SECURITY.md`, `ROADMAP.md`, and repository documentation for current build and development guidance.
